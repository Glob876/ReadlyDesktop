# Color themes

Brightness (`theme`: `light`, `dark`, `system`) and palette (`colorTheme`) are saved independently. Older profiles default to Readly; the old `sepia` brightness migrates to the Sepia palette in light mode. Readly keeps the user's custom accent. Named palettes define their own accent for a consistent appearance.

Every palette has light and dark variants. Menu rows preview the effective variant, including when the operating system changes in Auto mode. Choosing a theme previews it; Save persists both settings and Cancel restores the saved appearance.

Palette references:

- GitHub: [Primer primitives](https://github.com/primer/primitives/tree/main/data/colors).
- Catppuccin: [Latte and Mocha palette](https://github.com/catppuccin/catppuccin#-palette).
- Gruvbox: [original palette](https://github.com/morhetz/gruvbox/blob/master/colors/gruvbox.vim).
- Nord: [official colors and palettes](https://www.nordtheme.com/docs/colors-and-palettes/).

These are adaptations for Readly's interface roles. Matrix is an original green palette inspired by the film; Sepia and Readly use the existing Readly colors, with an added dark Sepia variant. Additional surfaces and contrast adjustments are specific to this application.
