# Readly Legacy

Классический интерфейс `Readly.pyw` из [Glob876/MogDop-Readly](https://github.com/Glob876/MogDop-Readly), коммит `ae30005` (ветка master). Расширенная версия `MogDop's Readly.pyw` не включена.

Сохранены вкладки, режимы проверки, темы и настройки оригинала. Изменения для интеграции: поддержка Linux, необязательный системный звуковой проигрыватель, переносимая иконка, отдельная папка данных, заголовок Readly Legacy. Начальный текст заменён отрывком из «Зимнего утра» А. С. Пушкина. Пользовательские файлы из исходного репозитория не переносятся.

Запуск из исходников: `./run.sh --legacy`. Нужен Python 3.12+; В Linux используется системный Python с Tkinter и Xft (поддержкой системных шрифтов), в Windows при наличии uv — отдельный Python 3.12. Для создания окружения нужен uv либо venv и pip. Скрипт автоматически создаёт `.legacy-venv` и устанавливает зависимости из `requirements.txt`, не изменяя системные Python-пакеты. Первый запуск требует интернета, следующие — нет.

`./build.sh` собирает самостоятельный Readly Legacy через PyInstaller и устанавливает его вместе с современным Readly. Для запуска установленного приложения Python не нужен. `./build.sh --no-legacy` отключает Legacy; `--pack-only` сохраняет оба приложения в переносимой сборке. Linux → Windows кросс-сборка содержит только современный Readly; чтобы включить Legacy, собирайте на Windows через `build.cmd`.

Данные Legacy: `$XDG_DATA_HOME/readly-legacy` (по умолчанию `~/.local/share/readly-legacy`) в Linux, `%APPDATA%\ReadlyLegacy` в Windows. Путь можно изменить через `READLY_LEGACY_DATA_DIR`. `stih.txt` — текст для обучения, `settings.txt` — настройки в JSON. Обновление приложения их не перезаписывает. Кнопка «Открыть папку» открывает именно этот каталог.

В Linux bootstrap проверяет наличие Xft: сборки Tk без него не поддерживают нормальную отрисовку системных шрифтов. При необходимости локальные библиотеки Tcl/Tk 8.6 можно расположить в `.legacy-tk/usr/lib` рядом с виртуальным окружением; они попадут в самостоятельную сборку.
